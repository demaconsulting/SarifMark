# Introduction

This document contains the build notes for SarifMark. It accompanies each release by
summarizing generated release notes and recorded build environment details for developers,
users, contributors, and project stakeholders.

## Purpose

This document provides a record of the changes, new features, and bug fixes included
in this release of SarifMark. It also records the versions of the tools used in the
build and compliance pipeline, providing traceability between the released artifacts
and the environment that produced them.

## Scope

This build notes report covers:

- Version information and commit details for this release
- Changes and new features implemented since the previous version
- Bugs fixed in this release
- Versions of the tools used in the build and compliance pipeline
- Generated content produced from repository history and pipeline tooling for this
  release package
